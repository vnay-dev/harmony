# Harmony

A Shruti app (pitch drone) for everyone.

## About

Harmony is a simple pitch drone for finding and practicing with your **Sa**.

## Features

* 12 Sa pitches
* Sa, Pa, and Ma drone notes
* Tanpura recordings
* Play and pause

## Tech Stack

* Flutter
* Dart

## Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK
* Android Studio or Xcode

### Run locally

```bash
flutter pub get
flutter run
```
